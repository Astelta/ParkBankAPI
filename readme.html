Health Check

GET
/health
Public

Basic health check endpoint that returns a simple "ok" status. Used for load balancer health checks and basic service monitoring.

Payload: None
ok

User Registration

POST
/register
Public

User registration endpoint that creates a new user account. Requires JSON payload with username and password fields. Passwords are securely hashed before storage.

Payload (JSON): 
{
  "username": "example_user",
  "password": "secure_password123"
}
User registered successfully

POST
/login
Public

User Profile

GET
/profile
Auth Required

Returns the authenticated user's profile information including user ID and balance. Requires a valid JWE token in the Authorization header.

Headers: 
Authorization: Bearer <jwe_token>
{ "id": 1, "balance": 100.50 }

Transfer Funds

POST
/transfer
Auth Required

Transfers funds from the authenticated user's account to another user. Requires a valid JWE token and a JSON payload specifying the recipient and amount.

Headers: 
Authorization: Bearer <jwe_token>
Payload (JSON): 
{
  "recipient_id": 2,
  "amount": 50.00
}
Transfer successful

User Logout

POST
/logout
Auth Required

Logs out the authenticated user by invalidating their JWE token. Requires a valid token in the Authorization header.

Headers: 
Authorization: Bearer <jwe_token>
Logout successful

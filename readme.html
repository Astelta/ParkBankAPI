API Endpoints

Successful responses use {"message": "...", "data": ...}. Error responses use {"error": {"code": "...", "message": "..."}}.

Health Check

GET
/health
Public

Basic health check endpoint that returns a simple "ok" status. Used for load balancer health checks and basic service monitoring.

Payload: None
{ "message": "API is healthy", "data": { "status": "ok" } }

User Registration

POST
/register
Public

User registration endpoint that creates a new user account. Requires JSON payload with nickname and password fields. Passwords are securely hashed before storage.

Payload (JSON): 
{
    "nickname": "example_user",
    "password": "secure_password123"
}
{ "message": "User registered successfully", "data": { "nickname": "example_user" } }

User Login

POST
/login
Public

Authenticates a user and returns a JWE token for subsequent authenticated requests. The token is AES-encrypted and contains user info with a 24-hour expiration.

Payload (JSON): 
{
    "nickname": "example_user",
    "password": "secure_password123"
}
{ "message": "Login successful", "data": { "token": "eyJhbGciOiJBRVNFTC1HQ00iLCJlbmMiOiJBMjU2R0NNIiwidmYiOiJBUkQxMjM0NTY3ODkwIiwiY3QiOiJBMTIzNDU2Nzg5MCJ9..." } }

User Profile

GET
/profile
Auth Required

Returns the authenticated user's profile information including user ID and balance. Requires a valid JWE token in the Authorization header.

Headers: 
Authorization: Bearer <jwe_token>
{ "message": "Profile retrieved successfully", "data": { "id": 1, "balance": 100 } }

Transfer Funds

POST
/transfer
Auth Required

Transfers funds from the authenticated user's account to another user. Requires a valid JWE token and a JSON payload specifying the recipient and amount.

Headers: 
Authorization: Bearer <jwe_token>
Payload (JSON): 
{
    "recipient_id": 2,
    "amount": 50.00
}
{ "message": "Transfer successful", "data": { "sender_id": "1", "recipient_id": 2, "amount": 50 } }

User Logout

POST
/logout
Auth Required

Logs out the authenticated user by invalidating their JWE token. Requires a valid token in the Authorization header.

Headers: 
Authorization: Bearer <jwe_token>
{ "message": "Logout successful" "data": { "status": "ok" } }

User Info

GET
/user
Auth Required

Returns the authenticated user's information including user ID, nickname. Requires a valid JWE token in the Authorization header. *The id is always checked first even if nickname is provided*

Headers: 
Authorization: Bearer <jwe_token>
Payload /GET: 
    parkbankapi.com/user?id=1
or 
    parkbankapi.com/user?nickname=john_doe
{ "message": "User retrieved successfully", "data": { "id": 1, "nickname": "john_doe" } }

Transactions

GET
/transactions
Auth Required

Returns the authenticated user's transaction history. Requires a valid JWE token in the Authorization header. The endpoint supports pagination with optional limit and offset parameters. Also the limit has a hardcoded maximum value of 50. If no records are found, an 404 error is returned.

Headers: 
Authorization: Bearer <jwe_token>
Payload /GET: 
    parkbankapi.com/transactions?limit=10&offset=0
{ "message": "Transactions retrieved successfully", "data": [ { "id": 36, "sender_id": 10, "recipient_id": 5, "amount": 1983819, "created_at": "2026-11-15T04:58:20.100656Z" } ] }
